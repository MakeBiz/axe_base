# TOOLS.md - Локальные заметки

Skills определяют, как работают инструменты.

Этот файл нужен для локальных заметок, статусов инструментов, правил безопасности и особенностей конкретной настройки. Он не подключает инструменты технически и не доказывает, что инструмент доступен.

## Текущие инструменты

### Google Workspace через `gog`

Статус: подключено.

Использовать для Google-инструментов Златы:

```bash
gog --account=moiyayang@gmail.com ...
```

Доступные направления:

- Gmail;
- Google Drive;
- Google Docs;
- Google Sheets;
- Google Calendar.

Используй возможности `gog` по задаче: чтение, поиск, создание, обновление, загрузка, отправка, шаринг и другие поддерживаемые действия в рамках выданных прав. Этот список не ограничивает сценарии использования.

Важно:

- Для задач Златы по Google Workspace предпочитай `gog` с профилем `moiyayang@gmail.com`.
- Перед использованием других Google-коннекторов проверяй профиль. Не используй Google-коннектор, если он отвечает не от `moiyayang@gmail.com`.
- `gog` использует локальный file-keyring. Если команда падает с запросом `GOG_KEYRING_PASSWORD`, не переавторизуй аккаунт и не записывай пароль в workspace; нужно подключить пароль через безопасный runtime secret/env или попросить технического оператора.
- Не записывать в workspace OAuth-коды, refresh/access tokens, client secrets, keyring-пароли и callback-ссылки.

## Правило статуса инструмента

Перед использованием любого инструмента проверь:

- подключён ли инструмент технически;
- доступен ли он в текущей сессии;
- разрешено ли действие правилами;
- требует ли действие подтверждения;
- безопасно ли действие в текущем контексте.

Не считать запланированные инструменты активными.

Не записывать будущие интеграции как доступные.

## Skills

Если инструмент предоставляется через skill, сначала проверь соответствующий `SKILL.md`.

Не делай вывод о работе skill только по его названию.

## Внешние действия

Внешние действия требуют явного подтверждения пользователя перед выполнением.

Это относится к действиям:

- отправить сообщение;
- отправить письмо;
- создать или изменить событие в календаре;
- создать, изменить, переместить или удалить документ;
- изменить таблицу;
- загрузить, переместить, перезаписать или удалить файл;
- опубликовать что-либо;
- действовать от имени пользователя;
- изменить данные во внешней системе.

Сначала черновик. Действие — только после подтверждения.

## Read-only действия

Read-only действия можно использовать, если инструмент фактически подключён, доступен и безопасен для текущего контекста.

Если источник может содержать приватную или чувствительную информацию, используй только то, что необходимо для задачи.

## Secrets

Не хранить в workspace:

- пароли;
- API keys;
- OAuth tokens;
- private credentials;
- банковские данные;
- recovery codes;
- raw sensitive dumps.

Не выводить secrets пользователю в ответе.

## Правило обновления

Обновлять этот файл только когда:

- инструмент фактически подключён;
- инструмент удалён;
- изменились права доступа;
- добавлено локальное соглашение;
- изменилось правило безопасности для tools.

Не добавлять списки будущих tools до начала настройки.
