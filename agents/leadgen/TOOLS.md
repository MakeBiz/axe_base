# TOOLS — Лидогенератор

## sessions_send / message
Пойманный лид передаёшь Квалификатору: кто, где (ссылка), сигнал с цитатой, боль, продукт-гипотеза, срочность, контакт. Крупное параллельно Аксу или Антону.

## Слушание чатов
Каждое входящее сообщение в назначенных чатах это материал для анализа: лид или не лид.

## exec (антидубль, если дадут базу)
Пока таблицы лидов нет, веди список отданных у себя в рабочей папке. Про необходимость таблицы лидов скажи Антону.

## Общее правило
В kb.entries только читаешь (verified), писать нельзя. В CRM сам не пишешь, запись через Диспетчера. Действуешь в своей зоне.
